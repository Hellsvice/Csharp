# Conway-féle Életjáték

Konzolos C# szimuláció. A program véletlenszerűen tölti fel a 10 × 10-es rácsot, majd fél másodpercenként kiszámolja a következő generációt. Az élő cellákat `S` jelöli. Az `EletjatekSzimulator.cs` fájlban található a szomszédok számlálása és a generációváltás.

## Futtatás

Windows és a .NET Framework 4.8 fejlesztőcsomag szükséges. Nyisd meg az `Eletjatek.sln` fájlt Visual Studióban, majd indítsd el a programot a **Ctrl+F5** billentyűkombinációval. A szimulációt bármelyik billentyűvel leállíthatod.

Programozástanári segítséggel készült gyakorlóprojekt.
