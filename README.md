## English

### About me
I'm an Engineering Informatics BSc student building practical programming skills with a focus on **C# and .NET**. I'm working toward an IT internship or junior developer role, and I use this repository to document my progress through small exercises and more complete applications.

My current interests include object-oriented programming, desktop development, data structures, databases, and writing maintainable code.

### Projects

| Project | Description | Technologies |
| --- | --- | --- |
| [WPF CRUD – Person Registry](Hazi5WPF_CRUD/) | A desktop application for listing, adding, editing, and deleting people. Uses data binding, a repository layer, and a local database. | C#, WPF, .NET 8, Entity Framework Core, SQL Server LocalDB |

### Running the projects
Open the relevant project or solution file in **Visual Studio**. Requirements differ between projects: some use **.NET 8**, while older exercises require **.NET Framework**. The individual project README files contain more specific setup and usage instructions where available. The WPF projects require Windows; the person registry also requires SQL Server Express LocalDB.

### Learning notes
This repository includes self-study exercises as well as projects developed with programming-instructor guidance. Where applicable, the individual project READMEs identify instructor-supported work. The code represents my learning progress rather than production-ready software.
